# 🚀 DocMaster Pro - All-in-One Scanner & Document Hub

> **100% Client-Side, Unlimited Free Usage, Zero Server Cost, Google AdSense Ready.**

---

## 🌟 What Has Been Built:

1. **📸 Web CamScanner (`/scanner`):**
   - Live Camera Capture & File Upload.
   - Smart Filters: **Magic Color**, **B&W Xerox Mode** (Thresholding), Grayscale, Sharp Contrast.
   - Multi-Page Document Scanning into a single clean PDF.

2. **✏️ Scanned Document Text In-Place Editor (`/text-editor`):**
   - **Tesseract OCR Engine** running client-side in the browser.
   - Detects character & word bounding boxes.
   - **Auto-Font Family Matcher:** Times New Roman (Serif), Arial (Sans-Serif), Courier (Monospace).
   - **Auto-Ink Color Matcher:** Samples exact original ink shade from image strokes.
   - **Smart Inpainting:** Erases old text using background paper color and cleanly writes new text.

3. **📑 iLovePDF Core Suite:**
   - **Merge PDF (`/merge-pdf`):** Combine multiple PDFs with reordering.
   - **Image to PDF (`/image-to-pdf`):** Convert JPG, PNG, WebP to PDF with A4 fit.
   - Fast client-side `pdf-lib` engine with zero upload delay.

4. **🎯 Govt Exam 20KB-50KB Resizer (`/photo-resizer`):**
   - Exact size slider (10KB to 200KB).
   - Binary compression search to hit the exact target size for SSC, UPSC, and Bank portals.
   - Standard Passport dimensions (3.5cm x 4.5cm) preset.

5. **💼 Office & HR Generators:**
   - **Rent Receipt Generator (`/rent-receipt`):** Generates 1 to 12-month official rent receipts booklet with simulated Revenue Stamp for HRA tax exemption.
   - **Salary Slip Maker (`/salary-slip`):** Corporate payslip PDF with earnings, deductions, and company seal.

6. **💰 Monetization & SEO Ready:**
   - Strategic Ad Slots: Top Banner (728x90), Sidebar (300x250), and High-CTR Pre-Download screen.
   - Day 1 Instant Earning: Adsterra/Monetag slots + Tax/Student affiliate cards + Direct UPI "Buy a ₹20 Chai" modal.
   - Pre-built compliance pages: `/privacy`, `/terms`, `/about`, `/contact`.
   - Auto-generated `/sitemap.xml` for Google Search Console.

## ⚡ How to Run Locally:

Simply double-click the **`start-server.bat`** file in this folder, or open terminal and run:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
